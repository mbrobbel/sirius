# Translator fixtures

These serialized Substrait plans are generated by
`experimental/starrocks/crates/starrocks-plan-translator/tests/translate.rs`.
Rust tests compare generated bytes with these files; C++ tests parse the same
files through Sirius's native exchange rewrite.

- `starrocks_string_source.substrait`: BIGINT, VARCHAR, and CHAR source columns.
- `starrocks_sum_sink.substrait`: SUM(INTEGER) with an explicit BIGINT output cast.
- `starrocks_fetch_source.substrait`: modern LIMIT 1 / OFFSET 2 expressions.

To regenerate after an intentional translation change, run from
`experimental/starrocks`:

```bash
UPDATE_EXCHANGE_FIXTURES=1 pixi run -e cn cargo test -p starrocks-plan-translator
pixi run -e cn cargo test -p starrocks-plan-translator
```
